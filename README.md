# IEP Dual Dashboard

공공데이터와 RAG 기반 AI를 활용한 특수학급 개별화교육(IEP) 지원 플랫폼입니다.  
교사는 학생 관찰 기록을 기반으로 성취기준, 스캐폴딩 전략, 진로 추천을 확인할 수 있고, 학부모는 자녀의 학교생활과 성장 정보를 모바일 중심 UI에서 확인할 수 있습니다.

## 주요 기능

* 교사용 대시보드
  * 학생 현황 요약
  * 스캐폴딩 추천
  * 국어·수학 성취기준 검색
  * 피드백 기록 및 분석
  * 학생 역량 기반 진로 추천

* 학부모용 대시보드
  * 오늘의 학교생활 요약
  * 급식, 시간표, 준비물 정보
  * 학생 특성 확인 및 수정
  * 성장 경로와 진로 추천 확인

* AI/RAG 기능
  * 국어·수학 성취기준 데이터 기반 검색
  * 학생 상태에 맞는 스캐폴딩 전략 추천
  * 직업 데이터 기반 진로 추천
  * Gemini API 기반 분석 및 추천 응답 생성

## 이번 업로드 버전 수정 내용

이번 버전은 Figma에서 확정한 교사용·학부모용 웹 UI를 실제 프론트엔드에 반영하고, 백엔드 API와 연결해 실행 가능한 형태로 정리한 버전입니다.

### 프론트엔드 UI/UX 개선

* 교사용 대시보드, 추천, 기준, 기록, 진로 탭 화면을 실제 서비스 화면처럼 재구성했습니다.
* 학부모용 오늘, 생활, 특성, 진로 탭 화면을 교사용 화면과 유사한 정보 구조로 정리했습니다.
* 데스크톱/모바일 반응형 화면을 모두 구현하고, 모바일 탭에는 아이콘과 텍스트가 함께 보이도록 정리했습니다.
* 사이드 탭에는 아이콘 중심 내비게이션과 hover 시 탭 이름이 보이는 인터랙션을 적용했습니다.
* 전체 배경색을 완전한 흰색이 아닌 약한 회색 톤으로 조정해 카드 구분감을 높였습니다.
* 상단 로고를 제공된 SVG 로고로 교체했습니다.

### 교사용 화면 수정

* 학생 프로필과 학생 맥락 카드의 라벨/내용 배치를 정리해 긴 문장도 자연스럽게 보이도록 수정했습니다.
* 스캐폴딩 결과 카드를 `평가 요약`, `주요 학습 격차`, `근거 성취기준` 블록으로 나눠 가독성을 개선했습니다.
* 추천 전략 카드는 `추천 전략 1~4` 제목과 전략 내용이 구분되도록 정리했습니다.
* 근거 성취기준 카드의 관련도/일치도 표시와 문장 간격을 조정했습니다.
* 기록 탭의 피드백 개수 요약은 실제 누적 피드백 수를 기준으로 동작하도록 수정했습니다.
* 진로 탭의 역량 격차, 성장 제안, 단계별 경로 문구와 레이아웃을 서비스 화면에 맞게 다듬었습니다.

### 학부모용 화면 수정

* 기술 설명 중심 문구를 학부모가 이해하기 쉬운 서비스 문구로 변경했습니다.
* 최근 변화 카드에 `변화 기록 1~3` 제목을 붙이고 본문을 구분했습니다.
* 특성 입력 예시와 진로 대화 힌트도 제목/본문 구조로 통일했습니다.
* 학교생활, 내일 준비, 진로 대화 힌트 등 학부모에게 필요한 정보를 우선 노출하도록 정리했습니다.

### API 연동 및 데이터 표시

* 프론트엔드 API 레이어를 통해 학생 정보, 피드백 기록, 스캐폴딩 추천, 진로 추천, 학교생활 정보를 불러오도록 연결했습니다.
* 실제 API 연결 실패 시에도 시연 가능한 기본 데이터 fallback을 유지했습니다.
* 국어/수학 과목 선택값이 추천 요청에 반영되도록 정리했습니다.
* 목업 문구에 남아 있던 하드코딩 요약을 실제 데이터 기반 표시로 바꿨습니다.

### GitHub 업로드 준비

* `node_modules`, `dist`, Python 가상환경, SQLite DB, vector store, `.DS_Store`, `.env` 파일이 커밋되지 않도록 `.gitignore`를 정리했습니다.
* API 키 등 민감 정보는 `.env`로 관리하도록 README에 실행 방법을 남겼습니다.

## 프로젝트 구조

```text
.
├── client/   # Vue 기반 프론트엔드
├── mock/     # 프론트엔드 시연용 Mock API 서버
└── server/   # FastAPI 기반 백엔드
```

## 실행 방법

프론트엔드와 백엔드는 각각 별도로 실행합니다.

### 1. 백엔드 실행

```bash
cd server
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Windows PowerShell에서는 가상환경을 아래 명령어로 활성화합니다.

```powershell
.\venv\Scripts\activate
```

백엔드 기본 주소:

```text
http://127.0.0.1:8000
```

API 문서:

```text
http://127.0.0.1:8000/docs
```

### 2. 프론트엔드 실행

```bash
cd client
npm install
npm run dev
```

프론트엔드 기본 주소:

```text
http://localhost:5173
```

## 환경 변수

백엔드 실행 전 `server/.env` 파일을 생성해야 합니다.

```env
GEMINI_API_KEY=your_gemini_api_key
GEMINI_CHAT_MODEL=gemini-2.0-flash
SQLALCHEMY_DATABASE_URL=sqlite:///./iep.db
POSTGRES_PASSWORD=your_local_postgres_password
```

프론트엔드에서 백엔드 주소를 변경하려면 `client/.env` 또는 `client/.env.local`에 아래 값을 설정합니다.

```env
VITE_API_BASE_URL=http://localhost:8000
```
