## 개발 환경 설정

### 1. Node.js 설치 및 확인
* **권장 버전**: Node.js `v20.14.0` 이상
* **버전 확인**:
```powershell
node -v
```

### 2. 의존성 패키지 설치
* **명령어**: 프로젝트 구동에 필요한 모든 라이브러리(Vue, Tailwind 등) 일괄 설치
```powershell
npm install
```

### 3. 로컬 개발 서버 구동
* **명령어**: 실시간 코드 변경 사항 반영(HMR)을 위한 개발 서버 실행
```powershell
npm run dev
```
* **접속 주소**: `http://localhost:5173`

### 4. 프로젝트 빌드 및 배포
* **명령어**: 운영 환경 배포를 위한 정적 파일 최적화 및 빌드
```powershell
npm run build
```

## 주요 수정사항

이번 작업에서는 기존 임시 Vue 화면을 피그마 디자인 기준의 실제 대시보드 UI로 재구성했습니다.

* **교사용 대시보드 화면 구현**
    * `/teacher/overview`: 교사용 홈 화면
    * `/teacher/scaffolding`: 스캐폴딩 추천 입력 및 결과 화면
    * `/teacher/curriculum`: 성취기준 검색 화면
    * `/teacher/progress`: 피드백 기록 및 분석 화면
    * `/teacher/career`: 진로 추천 화면

* **학부모용 대시보드 화면 구현**
    * `/parent/overview`: 오늘의 요약 화면
    * `/parent/school`: 학교생활 정보 화면
    * `/parent/traits`: 학생 특성 확인 및 수정 화면
    * `/parent/career`: 진로 경로 및 추천 화면

* **반응형 모바일 UI 추가**
    * 교사용/학부모용 페이지 모두 모바일 화면에서 사용할 수 있도록 반응형 레이아웃을 적용했습니다.
    * 모바일 하단 탭에 아이콘과 텍스트를 함께 표시하도록 구성했습니다.
    * 학부모용 모바일 화면은 오늘, 생활, 특성, 진로 탭 구조에 맞게 별도 화면을 구성했습니다.

* **디자인 시스템 적용**
    * 피그마에서 정리한 Stripe 스타일 기반의 색상, 카드, 버튼, 탭, 그림자 스타일을 프론트엔드에 반영했습니다.
    * 전체 배경은 완전한 흰색 대신 약한 회색 톤으로 조정했습니다.
    * 데스크톱 사이드 탭에는 아이콘 기반 메뉴와 hover 시 텍스트가 나타나는 효과를 적용했습니다.

* **로고 및 아이콘 에셋 추가**
    * `src/assets/icons` 경로에 로고와 메뉴 아이콘 SVG 파일을 추가했습니다.
    * 교사용 탭과 학부모용 탭에서 각각 필요한 아이콘을 사용하도록 연결했습니다.

* **FastAPI 연동 구조 추가**
    * `src/api/index.js`에서 백엔드 API 호출 함수를 관리하도록 구성했습니다.
    * `VITE_API_BASE_URL` 환경변수를 통해 API 서버 주소를 변경할 수 있습니다.
    * API 호출 실패 시 화면 확인이 가능하도록 기본 샘플 데이터를 fallback으로 반환하게 구성했습니다.

* **라우팅 구조 정리**
    * `src/router/index.js`에서 교사용 페이지와 학부모용 페이지의 경로를 분리했습니다.
    * 탭을 클릭하면 해당 화면으로 이동하고, 현재 경로에 맞춰 활성 탭이 표시되도록 구성했습니다.

## 주요 디렉토리 구조

* **src/api**: FastAPI 서버와 통신하는 API 호출 함수 관리
* **src/assets/icons**: 로고 및 교사용/학부모용 탭 아이콘 SVG 관리
* **src/composables**: 학생 정보, 진행 기록 등 공통 상태 관리 로직
* **src/router**: 교사용/학부모용 페이지 라우팅 설정
* **src/views/teacher**: 교사용 대시보드 상세 화면
* **src/views/parent**: 학부모용 대시보드 상세 화면
* **src/App.vue**: 사용자 유형별 공통 레이아웃, 상단 영역, 탭 네비게이션 구성
* **src/style.css**: 전체 반응형 레이아웃과 Stripe 스타일 기반 디자인 시스템 정의
